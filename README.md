# Personal Portfolio / Web CV

Modern, responsive personal portfolio for showcasing Data Science skills, professional experience, highlighted projects, and educational background.

---

## Features

- **Hero:** Brief introduction and quick contact links
- **About:** Professional summary, education, resume, and personal highlights
- **Experience:** Work history and role contributions
- **Projects:** Featured data analysis and dashboard projects
- **Skills:** Technical skills icon cloud with hover labels
- **Contact:** Contact form with EmailJS
- **Responsive Design:** Optimized for mobile, tablet, and desktop

---

## Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Email Service:** EmailJS (`@emailjs/browser`)
